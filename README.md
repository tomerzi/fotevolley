# מעבדת הגובה — משחק סימון

פתחו את `index.html`. הדף עצמאי, כולל את התמונות, ופועל ללא התקנות או חיבור לאינטרנט.

שש משימות חדשות, שנבחרו בשל פער בין הצל האוטומטי למסלול. אין בהן חזרה על ששת מגעי החול שנבדקו לאחרונה או על סימוני הצל הידניים הקיימים. כל משימה מציגה שלושה פריימים מאותו קטע צילום, עם חיתוך תמונה ברזולוציית המקור. זום אינו מייצר פרטים חדשים.

סמנו את מרכז הכדור ואת מרכז הצל שלו באותו פריים. ״לא רואה״ ו״לא בטוח״ הן תשובות מועילות ומקבלות אותן נקודות השלמה. XP והתקדמות אינם ציון דיוק. הסימונים נשמרים מקומית בדפדפן; בסיום מייצאים JSON ומחזירים אותו בצ׳אט. אין העלאה אוטומטית ואין שינוי אוטומטי במודל.

הקואורדינטות המיוצאות הן של הסרטון המקורי: 1920×1080, 25fps, עם SHA של הסרטון ומזהה מערך המשימות. כל פריים שומר זוג נקודות ומצבי נראות בנפרד; לא מאחדים כדור מפריים אחד עם צל מפריים אחר. עיגול העזרה הוא רמז אוטומטי בלבד ואינו נשמר כסימון ידני.

`tasks.json` מכיל את מסגרת המשימות והחיתוכים ללא התמונות. אפשר לבדוק קובץ שהוחזר וליצור CSV לביקורת באמצעות:

```bash
python -m height.annotations fotevolley-height-quest-2026.11.11.json --out annotations-review.csv
```

הפקודה מאמתת סרטון, משימות וקואורדינטות. היא אינה מכניסה סימונים אוטומטית לאימון ואינה מניחה שהם מדויקים.
