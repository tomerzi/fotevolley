# גובה הכדור לאורך הסרטון

התוצאה: **`ball_height.csv`** – שורה לכל פריים בסרטון (`main_camera_clean_v2.mp4`, 15,586 פריימים) עם גובה מרכז הכדור
מעל החול במטרים, מיקום תלת-ממדי מלא, ואומדן אי-ודאות.

החישוב נעשה מאפס. לא נעשה שימוש בשום ניסיון קודם לחשב גובה, וגם לא ב-`homography_px_to_m.npy` הקיים –
המצלמה כוילה מחדש מקווי המגרש. הקלט היחיד:

* `correct_bbox/ball_boxes_corrected3.csv` – מיקום הכדור בתמונה
* `pose/vitpose_body25.csv` – מפרקי השחקנים
* הסרטון עצמו (לקווי המגרש ולצל של הכדור)
* מגרש 16×8 מ'

גובה הרשת (2.20 מ') **לא שימש לחישוב** – הוא נשמר כבדיקה בלתי תלויה (ראו "אימות").

### עמודות `ball_height.csv`

| עמודה | משמעות |
|---|---|
| `frame`, `time_sec`, `shot` | כמו בקובץ הכדור |
| `z_m` | **גובה מרכז הכדור מעל מישור המגרש (מטר)**. כדור מונח על החול = 0.11 (רדיוס הכדור). לגובה תחתית הכדור: להחסיר 0.11 |
| `x_m`, `y_m` | מיקום במגרש: x לאורך המגרש (0 = קו הבסיס השמאלי בתמונה, 16 = הימני, הרשת ב-7.9), y לרוחב (0 = קו הצד הקרוב למצלמה, 8 = הרחוק) |
| `z_sigma_m` | אי-ודאות (סטיית תקן אחת) של הגובה |
| `quality` | **A** – מאומת בצל או כדור על החול (82% מהפריימים), **B** – מודל פיזיקלי ממצלמה בלבד (13%), **C** – אמינות נמוכה, בעיקר כדור מוחזק ביד (5%) |
| `state` | `flight` במעוף, `ground` על החול, `held` מוחזק/צמוד לשחקן, `unknown` |
| `method` | `flight+shadow` / `flight` (ללא צל) / `ground` / `shadow` / `player-depth` / `held` / `interp` |
| `z_shadow_m` | מדידה ישירה של הגובה מהצל בפריים הבודד (בלי שום מודל תנועה) – עמודת ביקורת בלתי תלויה |
| `ball_observed`, `shadow_used` | האם הכדור זוהה בפריים / האם נמצא הצל שלו |
| `reproj_err_px`, `flight_id` | שגיאת הטלה חזרה לתמונה, מזהה המעוף ב-`flights.csv` |

כיסוי: גובה ב-13,261 מתוך 15,586 פריימים (85%); ב-12,425 מתוך 12,524 הפריימים שבהם הכדור מזוהה (99%).
ב-836 פריימים שבהם הכדור **לא** זוהה (למשל יצא לרגע מעל גבול התמונה) הגובה מושלם מהמסלול הפיזיקלי.
הפריימים החסרים הם בעיקר בין הנקודות, כשאין כדור בתמונה. גובה מרבי שנמדד: 5.78 מ'.

## איך זה עובד

1. **כיול מצלמה** (`lines.py`, `calibrate.py`). המצלמה קבועה לחלוטין לאורך הסרטון (נבדק: אפס תזוזה).
   מתמונת חציון של הסרטון נדגמו ארבעת קווי המגרש בדיוק תת-פיקסלי, והותאם מודל מצלמה מלא – מוקד, עיוות עדשה,
   מיקום וזווית – כך שהקווים יוצאים מלבן של 16×8 מ' (שגיאה 1.2 פיקסל). המצלמה נמצאת כ-7 מ' מאחורי קו הצד,
   בגובה 6.8 מ', כמעט בדיוק במישור הרשת.

2. **פילוח למעופים** (`segment.py`). בין נגיעה לנגיעה הכדור במעוף חופשי. תכנות דינמי מחלק את מסלול הכדור בתמונה
   לקטעים שכל אחד מהם מוסבר על ידי מעוף בליסטי בתלת-ממד, כדור שמתגלגל על החול, או "אחר".

3. **הצל של הכדור = מצלמה שנייה** (`shadow_candidates.py`, `sun.py`, `sun_fit.py`). זה לב השיטה.
   ברוב הסרטון יש שמש חזקה והכדור מטיל צל חד על החול. קרן המצלמה אל הכדור + קרן השמש דרך הצל נחתכות
   בנקודה אחת – טריאנגולציה אמיתית של מיקום הכדור, בלי שום הנחה על התנועה.
   כיוון השמש נמצא לכל קטע מתוך זוגות כדור–צל עצמם (אילוץ אפיפולרי לינארי + הצבעת Hough), והוא זז בצורה חלקה
   לאורך המשחק (גובה השמש יורד מ-48.4° ל-43.4°) – סימן שהגאומטריה נכונה.

4. **פתרון משולב** (`chain.py`). לכל קטע נפתרים כל המעופים יחד: מיקום הכדור בתמונה, מיקום הצל, רציפות המיקום
   בנקודות הנגיעה, חיבור לחול בנחיתה, מיקום השחקן הנוגע (אילוץ חלש), כוח הכובד וגרר האוויר.
   כשיש צל, המודל מרשה גם תאוצה נוספת קבועה (ספין/רוח).

5. **כשאין צל** (עננים: קטעים 29, 33, 34 ועוד מעופים בודדים – כ-15% מפריימי המעוף) הגובה נקבע מהפיזיקה בלבד:
   הקימור של המסלול בתמונה תחת כוח הכובד קובע את המרחק מהמצלמה, יחד עם רציפות בין מעופים, מיקום השחקנים וגודל
   הכדור בתמונה. פרמטרי הפיזיקה (גרר, שיפוע המגרש) כוילו על 255 המעופים שנמדדו עם צל (`calibrate_physics.py`).

6. **כדור על החול / מוחזק** – על החול הגובה הוא 0.11; כדור שמוחזק ביד מוערך לפי הצל או לפי מיקום השחקן (איכות C).

## אימות – עד כמה אפשר לסמוך על זה

**1. מצלמה-בלבד מול הצל** (`validate_camera_only.py`). הרצתי את כל המערכת *בלי* נתוני הצל והשוויתי, פריים-פריים,
למדידת הצל הישירה (`z_shadow_m`), שאינה תלויה בשום מודל תנועה. 5,763 פריימים:

| | שגיאת גובה |
|---|---|
| הטיה ממוצעת | 0.3+ ס"מ |
| חציון | 3.5 ס"מ |
| 68% מהפריימים | עד 5.7 ס"מ |
| 90% | עד 12.1 ס"מ |
| 95% | עד 18.2 ס"מ |

כלומר שתי שיטות בלתי תלויות (פיזיקה מול צל) מסכימות ברמת סנטימטרים. זה גם הדיוק הצפוי בקטעים המעוננים (איכות B).
בפריימים עם צל (איכות A) הפתרון המשולב צמוד למדידת הצל: חציון 1.2 ס"מ.

**2. גובה הרשת** (`validate_net.py`). הצל של סרט הרשת העליון על החול, יחד עם כיוון השמש שנמצא מהכדור בלבד, נותן
את גובה הרשת: **2.15 מ'** (חציון על 54 קטעים; האמיתי 2.20 מ'), וגובה הרשת עצמה 0.99 מ' (תקני: 1.00).
הרשת לא שימשה בשום שלב, כך שזו בדיקה בלתי תלויה של הסקאלה האנכית כולה.

**3. כוח הכובד.** התאוצה האנכית שנמדדה ב-255 המעופים עם צל: 9.96 מ'/ש² (אמיתי 9.81) – סטייה של 1.5%.
בנוסף נמדדה תאוצה אופקית קבועה של 0.2–0.25 מ'/ש² בכל הקטעים, שמתיישבת עם שיפוע של כ-1°–1.5° של מישור המגרש
ביחס לאופק (או עם רוח קבועה). הגובה שמדווח הוא מעל מישור המגרש.

**4. סבירות פיזית.** גובה הכדור ברגע המגע תואם את חלק הגוף: ראש – חציון 1.97 מ', כתף/צוואר 1.34, ברך/ירך 1.10,
כף רגל 0.96 (כולל בעיטות גבוהות מעל הרשת). בסך הכול 445 אירועים: 337 נגיעות שחקן, 81 מגעים בחול, 9 ברשת,
12 לא מזוהים ו-6 שקרו כשהכדור היה מחוץ לתמונה.

**5. בעין** – `ball_height_overlay.mp4`: על הסרטון מצויר קו אנך מהכדור אל הנקודה שמתחתיו על החול, הגובה במטרים,
ו**אליפסה אדומה במקום שבו הצל חייב להיות אם הגובה המחושב נכון**. בקטעים שטופי שמש אפשר לראות שהיא יושבת על
הצל האמיתי. כחול = מעוף עם צל, כתום = מעוף ללא צל, חום = על החול, סגול = מוחזק.

### מגבלות

* **סקאלה מוחלטת: ±2% בערך** (±8 ס"מ בגובה 4 מ'). כוח הכובד מרמז שהאורכים גדולים ב-1.5%, הרשת מרמזת שהם קטנים
  ב-2.3% – שני הסרגלים לא מסכימים בכיוון, ולכן לא תיקנתי. הכול נשען על כך שהמגרש באמת 16×8 מ'.
* **קטעים מעוננים** (איכות B): דיוק טיפוסי 4–6 ס"מ, עם זנב של עד ~20 ס"מ. מעופים קצרים מאוד (פחות מ-6 פריימים)
  או מבודדים מסומנים C.
* **איכות C** (5%): בעיקר כדור מוחזק ביד לפני הגשה / אחרי נקודה (הגובה מוערך לפי מיקום השחקן), אינטרפולציה ומעופים
  חלשים. `z_sigma_m` שם 0.25–0.4 מ'. כדור שמוחזק בלי תזוזה נראה בתמונה כמו כדור מונח על החול רחוק יותר; ההבחנה נעשית
  לפי הצל, לפי תנועת הכדור יחד עם השחקן ולפי רציפות עם המעוף הסמוך, והיא עלולה לטעות במקרים בודדים.
* 3 מעופים נפסלו כלא-פיזיקליים ומסומנים `unknown` (פריימים 3033–3039, 5873–5977, 10159–10163), כולם אחרי סיום
  הנקודה (למשל כדור שנבעט גבוה אל מחוץ לתמונה).
* כשהכדור נעלם מהתמונה לזמן ארוך ומשהו קרה לו בינתיים (אי אפשר לחבר את שני הצדדים למעוף אחד), הפריימים שבאמצע
  נשארים `unknown` ולא מנוחשים; האירוע מסומן `unseen` ב-`ball_contacts.csv`.
* זיהוי "מי נגע" ב-`ball_contacts.csv` הוא לפי המפרק הקרוב ביותר לכדור בתמונה, ולכן חלק הגוף מקורב בלבד.
  12 אירועים מסומנים `unknown` (שינוי מהירות בלי סיבה מזוהה).
* המודל מניח מעוף חופשי בין נגיעות. נגיעה עדינה מאוד שלא משנה את המסלול לא תזוהה כאירוע (הגובה עצמו לא נפגע).

## הרצה מחדש

Python 3 עם `numpy`, `pandas`, `Pillow` ו-`ffmpeg` בלבד (ללא OpenCV / SciPy).

```bash
cd ball_height
python lines.py background_median.png court_line_points.csv
python calibrate.py court_line_points.csv camera.json
python shadow_candidates.py camera.json shadow_candidates.csv     # ~18 דקות, עובר על כל הסרטון
python sun_fit.py camera.json shadow_candidates.csv sun_per_shot.csv
python calibrate_physics.py                                       # physics.json
python reconstruct.py                                             # ball_height.csv, flights.csv, ball_contacts.csv
python validate_camera_only.py
python validate_net.py
python plots.py
python render_overlay.py ball_height_overlay.mp4
```
